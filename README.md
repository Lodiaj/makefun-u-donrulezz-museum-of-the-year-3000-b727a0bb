A single museum label from the year 3000 for an ordinary object from today: a CAPTCHA. The year-3000 curator misreads it as a ritual in which humans proved they were human by identifying traffic lights — and the deadpan twist is that the robots passed the test while the humans did not.

Run with `node main.ts`. It writes the entry to `/output/entry.txt`.
